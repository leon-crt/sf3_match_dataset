## HOW TO USE
1. Clone the repo
2. Download the sfiii3nr1.zip and sfiii3.zip roms and place them in the emulator_build/roms/ folder, you can also copy them there from your Fightcade 2 folder
3. Install the required Python packages by running pip install -r requirements.txt
4. In a terminal, run the command "python get_replays *player_name*", where *player_name* is the Fightcade 2 username of the player whose replay history you want to download. This will open up the fbneo emulator and sequentially record all of their replays while fast forwarding them.
